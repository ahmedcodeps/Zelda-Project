# Zelda-Project
A small recreation of TLoZ on the NES, made in LOVE with Lua.

## Credits:
Credits to Mister Mike for all the sprites used.
Credits to Sheepolution for guides on collision and game mechanics

## How to run:
1. Download LÖVE from https://love2d.org
2. Use the following command on Bash (make sure you cd into your project):
### Windows: "C:path/to/love/ LOVE/love.exe" .
### Mac: ~/path/to/love ~/path/to/your-project
